## Run Locally

### First Time Setup

1. Install dependencies locally:
   ```bash
   bundle install --path vendor/bundle
   ```

2. Start the Jekyll server:
   ```bash
   bundle exec jekyll serve
   ```

3. Open your browser to `http://localhost:4000`

### Subsequent Runs

```bash
bundle exec jekyll serve
```

## Configuration

- **Content**: Edit `_config.yml` for personal information
- **Experience**: Update `_data/experience.yml`
- **Skills**: Update `_data/skills.yml`
- **Education**: Update `_data/education.yml`
- **Intro**: Edit `_includes/header-intro.html`
- **Colors**: Modify `_sass/_variables.scss`
- **Styling**: Adjust `_sass/_resume.scss`
